# Набір спрайтів чоловічого персонажа 017

Готові до імпорту окремі RGBA PNG лежать у sprites/. Це набір одного чоловічого персонажа, не жіночого. Вихідні розміри деталей різні; масштаб і кріплення задані в pack.json. Не вирівнюйте їх за розміром PNG.

## Склад

- body-olive.png / body-camo.png — тіло з ногами, без голови та повних рук.
- head-bare.png / head-equipped.png — голова з волоссям / цілісна голова з шоломом, окулярами й маскою.
- arm-front-olive.png / arm-front-camo.png — права рука біля спускового гачка.
- arm-left-olive.png / arm-left-camo.png — виправлена ліва підтримувальна рука. Попередні дві неправильні руки виключено зі sprites/.
- vest.png — окрема розгрузка.
- rifle.png — окрема зброя.

Камуфляж, рукави й екіпірована голова перемикаються одним комплектом. Розгрузка та зброя незалежні. Без кобури та видимої кишені на лівому рукаві.

## Перегляд

Відкрийте index.html безпосередньо або запустіть node serve.cjs і перейдіть на http://127.0.0.1:8770/. Є легке дихання та кнопка віддачі. Руки змінюють масштаб і кут між плечем та хватом; складного ліктьового деформування немає. Дихання масштабує силует від опори біля стоп. Параметри: pack.json; порядок шарів відповідає order.

## Unity

1. Скопіюйте папку sprite-pack-male-017 у Assets вашого Unity-проєкту.
2. Виділіть цю папку у Project, виберіть Assets > Low Poly Male 017 > Create character from selected pack folder.
3. Увімкніть Play. Створений об'єкт має компонент LowPolyMale017. Equipped перемикає комплект, ShowVest/ShowWeapon — окремі предмети.
4. Викликайте Fire() при події пострілу. Координатна опора об'єкта біля стоп; 100 пікселів на одиницю. Для лівого напрямку можна віддзеркалити весь кореневий об'єкт по X.

Імпортер налаштовує прозорість, Bilinear, без mipmaps і без стиснення. Зображення створюються через Sprite.Create з pivot у верхньому лівому куті. Unity-скрипти підготовлені, але не запускалися в Unity в цій сесії; підтверджений перегляд — браузерний. Ігрові механіки не змінювалися.

## Перевірка і джерела

Переглянуто звичайний та екіпірований комплекти, віддачу. Після зауваження користувача ліва рука перегенерована: великий палець праворуч у вигляді долоні, лікоть видно праворуч від тулуба. Це перевірка реалізації; схвалення арту користувачем не припускається.

atlas.png та atlas-rects.json — вихідний атлас ДО виправлення лівої руки, не актуальний набір для імпорту. Використовуйте виключно sprites/ і pack.json. source/ містить відкинуті варіанти. export-sprites.ps1 відтворює первинне нарізання атласу; не запускайте для оновлення готового набору.

Використано built-in image_gen за наданим користувачем еталоном. Атлас нарізано без зміни кольору чи масштабу пікселів; наступні виправлення рукавів виконано image_gen. Запити й джерела — PROVENANCE.md.
