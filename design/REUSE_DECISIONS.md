# Реєстр повторного використання ідей

Поточний стан: **жодної ідеї з Project Airsoft / Airsoft Manager не прийнято як повторне використання**. Існуючі specs нового проєкту не є продовженням їхніх рішень.

Для кожної майбутньої пропозиції потрібні:

| Поле | Зміст |
|---|---|
| ID | REUSE-### |
| Source | Конкретне джерело ідеї; не автоматичний імпорт усієї системи |
| Proposed idea | Що саме пропонується |
| New-game problem | Яку потребу цієї нової гри вирішує |
| Alternatives | Незалежні варіанти реалізації |
| Justification | Чому підходить до швидкого management/social loop |
| Impact | Вплив на scope, combat, economy, UX та залежності |
| Decision / status | Proposed, adopted або rejected; хто й коли прийняв |
| Boundaries | Що залишається незалежним; права на assets/code оцінюються окремо |

Без конкретного adopted запису ідея не стає вимогою нової гри. Навіть adopted idea не дозволяє змінювати Project Airsoft, імпортувати його Git-історію чи автоматично копіювати implementation.
