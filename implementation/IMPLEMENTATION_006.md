# Implementation 006 — durable authoritative battles

Accepted offense and published defense are encoded with the unchanged BattleWire schema1, server-generated seed and complete rules. Economy version/config, opponent level and prepared powers are archived. Acceptance atomically records Pending and blocks own mutations. Resolve occurs outside transactions using the shared engine; no client result submission exists. Settlement atomically writes actual attacker HP/BB, participant XP, wallet ledger, completion counter and new defense snapshot. Defender live HP/BB are untouched. Reply retries read the stored operation response before expected-version validation.

A restart-safe worker scans durable pending matches. Lease120seconds with fencing rejects expired/late settlement as technical Failed, clears pending and gives no resources/rewards/counter. This conservative cancellation is explicit rather than silently producing a rewarded Draw. Atomic DB snapshot storage is the publication mechanism; there is no external projection requiring an outbox yet. A meter counts settlements; worker logs error types without payloads/secrets.
